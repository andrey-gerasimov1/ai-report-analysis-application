# Synthetic review fixtures

These small HTML files are entirely fictional examples for demonstrating the application. Their companies, market values, and forecasts are invented; they are not real research or investment advice. The filenames match the sample registry entries so the repository can be reviewed and run without any third-party reports.

On a fresh checkout, copy both `.html` files into `data/reports/` before running the app or its integration tests. Do not overwrite report files you already have locally.
